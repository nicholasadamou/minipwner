# MiniPwner brand kit

**Pocket-sized penetration testing.**

## Identity

A white pocket-router mascot based on the TP-Link TL-MR3040: slim rounded shell, silver seam, teal status strip and cable, and a confident expression. Keep the device white and antenna-free.

The mascot is the standalone logo. Social artwork combines it with the project wordmark. Use the same mascot consistently; the board illustrates applications rather than supplying logos to crop out.

## Assets

- `logo.png`: transparent full-color mascot master.
- `social-preview.png`: wide README image with mascot and wordmark.
- `social-preview.jpg`: upload-ready 1280 × 640 version, below GitHub’s upload limit.
- `brand-board.png`: identity overview with palette, typography, clear space and applications.

## Typography

The wordmark in the social artwork is custom illustrated lettering. Use Plus Jakarta Sans for supporting headings and copy, and JetBrains Mono for commands and technical metadata. GitHub README text uses GitHub's own fonts.

## Usage

Keep at least 10% clear space around the mascot. Preserve its proportions, face, colors and accessories. Use the transparent master on a plain contrasting background; never stretch it to fit a square. At small sizes, prefer at least 48 pixels of height so the expression stays readable.

README order: left-aligned logo beside the project name, social preview on the next block, then technology/status badges, followed by the project description.

The social preview contains the logo and wordmark together. Keep all essential artwork within the supplied safe margins. Use the standalone logo for avatars and header placement.

## Source and exports

The mascot, artwork and wording are specific to this project. Raster masters retain their transparency; the preview is exported for GitHub at 1280 × 640. The brand board is a presentation reference. See the accompanying prompt archive for the artwork specifications.
